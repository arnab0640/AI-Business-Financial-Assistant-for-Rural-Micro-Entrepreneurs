## 📌 Project Overview
**GrameenVikas AI** is a state-of-the-art AI-driven web platform designed for **Smart India Hackathon 2026 (SIH 2026)** for the **Ministry of Social Justice and Empowerment (MoSJE)**. It empowers rural micro-entrepreneurs, artisans, Self-Help Groups (SHGs), and small business owners from SC, ST, OBC, and Safai Karamchari communities across India with hyper-local business intelligence, official government scheme matching, and automated financial structuring.

## ✨ Topics & Key Capabilities

1. 🏆 **SIH 2026 Introductory Screen & Executive Brief:** Grand hackathon cover screen featuring problem objectives, target demographics, and solution impact.
2. 🗣️ **AI Business Advisory Copilot:** Instant business advice in **7 regional languages** (English, Hindi, Bengali, Tamil, Marathi, Gujarati, Telugu) with Web Speech Voice Input and Audio Readout (Text-to-Speech) for illiterate/semi-literate accessibility.
3. 📊 **Hyper-Local Market Demand Predictor:** Village and district-level market feasibility index, competitor density analyzer, profit margin estimator, and raw material availability scores visualized via interactive Radar Charts.
4. 🏛️ **MoSJE Financial Scheme Matcher:** Rule-based AI engine matching entrepreneurs with official government schemes:
   - **VISVAS Scheme** (5% Interest Subvention)
   - **NSFDC Micro-Credit & Mahila Samriddhi Yojana**
   - **NBCFDC & NSKFDC Concessional Loans**
   - **PM-DAKSH Skill & Entrepreneurship Grants**
   - **PMMY MUDRA Loans** (Shishu, Kishor, Tarun)
5. 💰 **Financial Structuring Engine:** Live cash flow simulator, 12-month net profit forecasting, break-even analysis, and subvented EMI calculators.
6. 📄 **1-Click Bankable Project Report (DPR) Generator:** Generates official print-ready Detailed Project Reports formatted specifically for District Industry Centers (DIC), Banks, and NABARD.
7. 🛍️ **Hyper-Local Market Linkage:** Direct producer-to-buyer network linking rural artisans with GeM (Government e-Marketplace) and ONDC e-commerce channels.

## 🛠️ Tech Stack

- **Frontend:** HTML5, Modern ES6+ JavaScript, Custom CSS3 (Glassmorphism & SIH 2026 Saffron Gold Palette)
- **Mobile & PWA Support:** Progressive Web App (PWA) with Manifest V3, Service Worker (`sw.js`), Apple Touch Icons for **iOS**, and Native Install Prompts for **Android & Windows**
- **Data & Charts:** Chart.js, FontAwesome Icons
- **Accessibility:** Web Speech API (Speech Recognition & Speech Synthesis)
- **Deployment & Server:** Python HTTP Server

## 📱 Android & iOS App Support

**SNU BizSathi** is built as an installable **Progressive Web App (PWA)** that runs natively on:
- 🤖 **Android:** Tap browser 3-dot menu $\rightarrow$ "Install App" / "Add to Home Screen".
- 🍎 **iOS (iPhone/iPad):** Open in Safari $\rightarrow$ Tap Share icon $\rightarrow$ "Add to Home Screen".
- 💻 **Windows / macOS:** Click the address bar install icon $\rightarrow$ "Install App".

Features include **offline caching** for remote rural areas with intermittent connectivity.

## 💻 Local Setup & Execution

1. **Clone the repository:**
   ```bash
   git clone https://github.com/arnab0640/AI-Business-Financial-Assistant-for-Rural-Micro-Entrepreneurs.git
   cd AI-Business-Financial-Assistant-for-Rural-Micro-Entrepreneurs
   ```

2. **Start the local server:**
   ```bash
   python -m http.server 8000
   ```

3. **Open in Browser:**
   Go to `http://localhost:8000`
