## 📌 Project Overview
**GrameenVikas AI** is a state-of-the-art AI-driven web platform designed for the **Ministry of Social Justice and Empowerment (MoSJE)** under **Problem Statement #91**. It empowers rural micro-entrepreneurs, artisans, Self-Help Groups (SHGs), and small business owners from SC, ST, OBC, and Safai Karamchari communities across India with hyper-local business intelligence, official government scheme matching, and automated financial structuring.

---

## ✨ Key Features

- 🗣️ **Multilingual & Voice-Enabled AI Copilot:** Instant business advice in **7 regional languages** (English, Hindi, Bengali, Tamil, Marathi, Gujarati, Telugu) with Web Speech Voice Input and Audio Readout (Text-to-Speech) for illiterate/semi-literate accessibility.
- 📊 **Hyper-Local Market Demand Predictor:** Village and district-level market feasibility index, competitor density analyzer, profit margin estimator, and raw material availability scores visualized via interactive Radar Charts.
- 🏛️ **MoSJE Financial Scheme Matcher:** Rule-based AI engine matching entrepreneurs with official government schemes:
  - **VISVAS Scheme** (5% Interest Subvention)
  - **NSFDC Micro-Credit & Mahila Samriddhi Yojana**
  - **NBCFDC & NSKFDC Concessional Loans**
  - **PM-DAKSH Skill & Entrepreneurship Grants**
  - **PMMY MUDRA Loans** (Shishu, Kishor, Tarun)
- 💰 **Financial Structuring Engine:** Live cash flow simulator, 12-month net profit forecasting, break-even analysis, and subvented EMI calculators.
- 📄 **1-Click Bankable Project Report (DPR) Generator:** Generates official print-ready Detailed Project Reports formatted specifically for District Industry Centers (DIC), Banks, and NABARD.
- 🛍️ **Hyper-Local Market Linkage:** Direct producer-to-buyer network linking rural artisans with GeM (Government e-Marketplace) and ONDC e-commerce channels.

## 🛠️ Tech Stack

- **Frontend:** HTML5, Modern ES6+ JavaScript, Custom CSS3 (Glassmorphism & Theme Design System)
- **Data & Charts:** Chart.js, FontAwesome Icons
- **Accessibility:** Web Speech API (Speech Recognition & Speech Synthesis)
- **Deployment & Server:** Python HTTP Server

## 💻 Local Setup & Execution

1. **Clone the repository:**
   ```bash
   git clone https://github.com/arnab0640/AI-Business-Financial-Assistant-for-Rural-Micro-Entrepreneurs.git
   cd AI-Business-Financial-Assistant-for-Rural-Micro-Entrepreneurs
   ```

2. **Start the local server:**
   ```bash
   python -m http.server 8000
   ```

3. **Open in Browser:**
   Go to `http://localhost:8000`
